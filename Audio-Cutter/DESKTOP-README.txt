2BZ 오디오 커터 v0.6 · Night Session · 너무바쁜베짱이

차콜 바탕, 부드러운 글자색과 앰버 강조로 편집 화면을 정리했습니다.

처음에는 음악 자르기만 표시합니다. 노래 → 구간 조정 → MP3 저장으로 사용하세요.
MP3 저장은 음악 파일만 한 폴더에 모읍니다.
상단 뮤비 프로젝트를 선택하면 아래 장면 기능을 펼칩니다.
두 화면을 오가도 음악·구간·장면 자료는 유지됩니다.

1. 노래를 넣고 원하는 초로 나눈 뒤 위쪽 파형의 경계를 조정합니다.
2. 왼쪽에서 장면을 고르고 가운데에서 이미지·프롬프트를 편집합니다.
3. 오른쪽 공통 자료함에 캐릭터·의상·배경을 등록하고 이름을 붙입니다.
   자료 카드의 장면/시작/끝 버튼으로 현재 장면에 넣을 수 있습니다.
4. 블록 나눠 복제는 선택 블록을 반으로 나누며 자료를 복사합니다.
   이전 장면 자료 가져오기는 이전 블록의 이미지·프롬프트를 가져옵니다.
5. 장면 상태를 준비 중/생성 대기/생성 완료로 표시합니다.
   결과 영상을 넣으면 완료로 표시되고 앱에서 미리 볼 수 있습니다.
6. 마지막 프레임 → 다음 장면 시작으로 버튼으로 장면을 연결합니다.
7. 장면 꾸러미 저장 시 장면별 업로드 폴더에 음악과 이미지를 모읍니다.
   프롬프트·결과 영상은 그 옆에 저장합니다. 역할과 순서는 생성 사이트에서 확인하세요.

편집은 자동 저장됩니다. 상단의 자동 저장 완료 표시를 확인하세요.
프로그램 종료 시 마지막 변경을 저장하고, 다음 실행 시 최근 작업에서 이어 작업하기를 눌러 복구합니다.
자동 저장은 이 PC의 LOCALAPPDATA/2BZ-Audio-Cutter/recovery에 보관합니다.
다른 PC로 옮기거나 백업하려면 프로젝트 저장으로 .2bz 파일을 만드세요.
.2bz에는 원곡·이미지·결과 영상·자료함·장면 상태·선택 블록이 포함됩니다.

프로젝트 파일: EXE 옆 projects / 장면 꾸러미: EXE 옆 exports
저장 후 탐색기가 자동으로 열립니다. 자동 저장은 탐색기를 열지 않습니다.
EXE와 _internal 폴더를 함께 보관하세요. Python·FFmpeg는 포함되어 있습니다.
Windows 10/11 64비트와 Microsoft Edge WebView2 Runtime이 필요합니다.
https://developer.microsoft.com/microsoft-edge/webview2/
