# ③ 사용 순서 — 이미지 편집 (레퍼런스 최대 10장)

1. **Load Image ①** = 편집할 원본(image_1). **Load Image ②** = 옷·소품·배경 등 가져올 것(image_2). 더 필요하면 노드 안 images 슬롯에 계속 연결.
2. **prompt** 에 지시. `<image1>`, `<image2>` 로 사진을 가리킵니다. 유지할 것을 명시하면 덜 흔들립니다: `Keep everything else exactly unchanged.`
3. **custom_size OFF**(기본)면 출력 크기 = image_1을 1024 예산으로 리사이즈한 크기. **ON**이면 Resolution Selector 크기.
4. Queue. 아래 **Image Compare** 로 전후를 슬라이드 비교.

## 실행 전 확인 (실측에서 나온 것)
- **편집에는 시드 의존 실패가 있습니다.** 같은 입력·프롬프트에서 어떤 시드는 이미지 전체가 과포화로 타고, 다른 시드는 정상. 타면 시드를 바꾸세요(2~3개 돌려보기). 스케줄러 노드로는 안 잡힙니다.
- 3090: 1ref 33s, 3ref 96s. 4070TiS: 30s / 77s.
- 한글 텍스트 교체('너무바쁜베짱이')는 됩니다. 색·그라데이션까지 유지.
