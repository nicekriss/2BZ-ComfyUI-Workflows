# Qwen-Image 2.1 · 360 파노라마 (컴피UI 워크플로우 소개 #1)

그림 한 장 → 360 파노라마(2:1) → 좌우 이음새 고치기 → 8K(8192×4096).

- 워크플로우: `2BZ_Qwen21_05_360_Panorama.json` — 안의 메모 노드에 모델 다운로드 링크·저장 경로·사용 순서가 있습니다.
- 360 영상 파일 만들기: `360영상만들기.zip` 을 받아 풀고, 8K PNG를 `360영상만들기.bat` 에 끌어다 놓으면 `<이름>_360.mp4` 가 생깁니다. 필모라 등 편집기에서 360 영상으로 인식됩니다.
  - 파이썬은 컴피UI(데스크톱·포터블)에 들어 있는 것을 자동으로 찾아 씁니다. ffmpeg가 없으면 받는 곳을 안내합니다.
  - 그래픽카드 인코더(NVIDIA·AMD·인텔)가 없으면 CPU로 만듭니다(8K는 몇 분).

RTX 3090 실측: 처음부터 8K까지 약 3분 55초(모델 로드 포함), VRAM 카드 전체 기준 최고 약 23GB.
Qwen-Image 2.1은 연구용 라이선스라 상업 목적 사용은 막혀 있습니다.
