# 처음 시작하기 — Photoshop에서 그리고 ComfyUI로 완성하기

포토샵에서 그린 선화를 ComfyUI로 채색하고, 결과를 다시 포토샵 레이어로 받는 구성입니다.
설치 도우미가 노드·모델·플러그인·워크플로우를 한 번에 잡아줍니다.

## 준비물

- Windows + NVIDIA 그래픽카드 (전용 메모리 8GB 이상 권장)
- Photoshop 2025 이상 (플러그인이 최신 버전에서만 동작합니다)
- ComfyUI Desktop — 없으면 [comfy.org/download](https://www.comfy.org/download)에서 설치하고 한 번 실행해 주세요
- 저장 공간 약 20GB (모델을 새로 받는 경우)

## 설치

1. 이 폴더를 한글·공백이 없는 짧은 경로에 두세요. 예: `D:\PhotoshopAI`
2. **ComfyUI와 Photoshop을 모두 종료**하세요. 켜져 있으면 새 노드와 플러그인이 반영되지 않습니다.
3. `설치하기.bat`을 더블클릭합니다.

설치 도우미가 순서대로 진행합니다.

| 단계 | 내용 |
|---|---|
| 1 | 내 PC 확인 — GPU·RAM·Photoshop·ComfyUI·여유 공간 |
| 1-1 | 모델 저장 위치 선택 — 드라이브별 여유 공간을 보여주고, SSD가 좁으면 다른 드라이브(HDD) 문자만 입력하면 됩니다. ComfyUI 등록까지 자동입니다 |
| 2 | 설치할 구성 안내 후 확인 |
| 3 | ComfyUI 노드 설치 (sd-ppp, KJNodes) |
| 4 | 모델 3개 다운로드 및 SHA256 검증 |
| 5 | 워크플로우 복사 |
| 6 | Photoshop 플러그인 설치 + 입력창 포커스 패치 |
| 7 | 연결 확인 — 서버 주소를 클립보드에 복사 |

중간에 누르실 곳은 다섯 군데입니다. ComfyUI 선택 → 모델 저장 위치 → 설치 확인 → Creative Cloud 플러그인 설치 → ComfyUI 재시작.

HDD에 모델을 두면 ComfyUI를 켜고 첫 생성 때 모델을 읽는 데 1~2분 걸릴 수 있습니다. 고장이 아니며, 한 번 올라간 뒤에는 속도가 같습니다.

## Civitai 로그인이 필요한 모델

체크포인트와 LoRA는 Civitai에서 받는데, 제작자 설정에 따라 **로그인한 사용자만** 받을 수 있습니다.
설치 도우미가 이 상황을 만나면 두 가지 방법을 안내합니다.

1. **API 키 입력 (추천)** — Civitai에 로그인 → 계정 설정 맨 아래 **API Keys** → `Add API key`로 만든 키를 붙여넣습니다. 한 번 입력하면 나머지 모델도 자동으로 받습니다. 키는 저장하지 않습니다.
2. **브라우저에서 직접 받기** — 모델 페이지를 열어 드립니다. 로그인해서 받은 뒤 Enter를 누르면 다운로드 폴더에서 파일을 찾아 옮기고, 해시를 확인한 뒤 이어서 진행합니다.

Civitai 계정은 무료입니다.

## 설치 후 첫 테스트

1. Photoshop 실행 → 플러그인 → SD-PPP 패널 열기
2. 설치 도우미가 복사해 준 주소(`http://127.0.0.1:8188`)를 입력하고 연결
3. 입력창에 한 문장 치고 다른 곳 클릭 — 글자가 그대로 있으면 정상입니다
4. 워크플로우에서 `2BZ_Photoshop_Sketch_Color` 선택 → 그림 가져오기 → 실행
5. 결과가 새 레이어로 도착하면 완료입니다

## AI 그림이 처음이라면

같은 폴더의 **`AI-그림-원리.html`**을 더블클릭해 보세요. 인터넷 없이도 열립니다.
노이즈에서 그림이 나오는 과정, 체크포인트, 프롬프트, ControlNet, LoRA, denoise, seed를 일곱 장면으로 정리했고,
슬라이더를 직접 움직이면서 패널의 각 값이 무슨 일을 하는지 확인할 수 있습니다.

## 워크플로우 사용법

- **`# 생성 방식` 스위치** — 끄면 선화만 쓰는 t2i, 켜면 색 밑칠을 함께 쓰는 i2i입니다
- **`# denoise`** — t2i는 1.0, i2i는 0.6~0.8에서 시작하세요
- **`# 붓터치 LoRA 강도`** — 0으로 내리면 LoRA가 꺼집니다
- **ControlNet strength** — 올리면 선화 구조에 충실하고, 내리면 AI가 더 많이 고칩니다

프롬프트는 영어로 씁니다. 그림의 색은 가져오지 않으니 머리색·옷색을 프롬프트에 직접 적어주세요.

## 업데이트하지 마세요

설치 도우미는 검증을 마친 sd-ppp 버전(2.0.0)을 고정해서 설치합니다.
ComfyUI Manager에서 sd-ppp를 업데이트하면 검증되지 않은 버전이 들어오고,
입력창 포커스 패치도 풀립니다.

실수로 업데이트했다면 `설치하기.bat`을 다시 실행하세요. 고정된 버전으로 되돌리고 패치도 다시 적용합니다.

## 문제가 생기면

- **플러그인 입력창에 글자가 안 남는 경우** — 포커스 패치가 적용되지 않은 상태입니다.
  `tools\patch-sdppp-focus.ps1`을 실행하고 Photoshop을 재시작하세요. 되돌리려면 `-Restore`를 붙입니다.
- **노드가 빨갛게 표시되는 경우** — ComfyUI를 재시작하세요. 새 노드는 재시작해야 읽힙니다.
- **패널이 서버에 연결되지 않는 경우** — ComfyUI가 실행 중인지, 주소의 포트 번호가 맞는지 확인하세요.
