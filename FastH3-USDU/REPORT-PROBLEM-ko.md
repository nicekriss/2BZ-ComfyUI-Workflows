## 반드시 첨부할 증거

- 설치 실패: 설치 창 전체 오류 캡처와 `ComfyUI/user/2bz-solattn-installer/install-*.log` 중 해당 시각 파일. USDU 설치는 창에 출력된 오류·staging 경로를 캡처합니다.
- ComfyUI 실행 후 실패: **실제로 실행한 워크플로우 JSON**, 전체 traceback 텍스트, 해당 실행 앞뒤 서버 로그. 마지막 오류 한 줄만으로는 원인 판정이 어려울 수 있습니다.
- `Check-ComfyUI.bat` 결과와 가능하다면 `Check-Setup.bat` 결과. CUDA 검사는 렌더를 멈춘 뒤 별도로 실행하세요.
- 설치 로그에 표시되는 H3 소스 검사 결과와 USDU 버전/수정본 여부도 필요합니다. 앱 업데이트 후 발생했다면 업데이트 전후 버전을 알려주세요.
- 모델 4개의 정확한 파일명과 바이트 크기. 다운로드 미완료 의심 시 SHA256도 요청할 수 있습니다. 모델 자체를 업로드하지 마세요.

## 영상 실행 문제라면 추가

```text
입력 가로×세로 / fps / 길이 / 프레임 수 (모르는 항목은 모름):
정규화 MP / upscale_by / steps / denoise / seed:
VSA 모드 / keep_percent / 켜짐·바이패스:
USDU batch_size / anchor_context / tiled_decode:
첫 실행인지 재실행인지 / 걸린 시간 / 멈춘 노드:
출력 가로×세로 / 길이 / 오디오 유무:
```

- 메모리 오류: OOM 전체 문구와 같은 시점 GPU 전용 메모리·시스템 RAM 사용량 캡처.
- 화질 문제: **원본과 결과의 동일 프레임·동일 부위** 비교, 가능하면 문제 전후 짧은 클립. 공개 가능한 비개인 샘플만 전달하세요. 샤프닝 수치만으로 판정하지 않습니다.
- 깜빡임/타일 경계: 발생 시간과 위치, 재현 빈도. 정지 이미지뿐 아니라 짧은 움직임도 필요합니다.
- 속도 문제: 동일 소스·범위·해상도·seed를 비교했는지, 모델 로딩/대기 포함 여부. 녹화 동시 여부도 구분하세요.

워크플로우 JSON과 로그에는 프롬프트·파일 경로가 포함될 수 있습니다. 첨부 전 내용을 열어 검토하세요. 입력 영상을 제공할 수 없다면 작은 공개 샘플에서도 같은 오류가 나는지 알려주세요. 설치기에는 자동 수집·외부 업로드 기능이 없습니다.
