# 시작하기 · FastH3 + USDU · v1.2.1

1. ZIP의 START-HERE-ko.md 순서로 어텐션·USDU를 설치합니다.
2. 이 워크플로우를 열고 **① 모델 다운로드 노트의 링크 4개**를 눌러 받습니다.
3. 각 폴더에 넣고 모델 로더를 확인한 다음 입력 영상을 선택합니다.
4. 추가 프롬프트는 평소 비워 두고, 짧은 영상부터 실행합니다.

한국어: 2BZ_FastH3_USDU.json / English: 2BZ_FastH3_USDU_EN.json.
두 버전은 설명 언어만 다르고 처리 설정·연결은 같습니다.
**⑥ 최신 테스트 결과**에 3방 비교표와 최종 선택 이유가 있습니다.

기본: 약 1MP 정규화 → 2배 / 2스텝 / denoise 0.20 / 전체 영상.
타일·조건부여 크기는 정규화된 입력에 자동 연결됩니다.
FHD·2048 고정 출력이 아닙니다. 출력: output/video/FastH3_USDU…mp4.

4070 Ti SUPER 16GB · RAM 32GB에서도 기존 업스케일 성공(사용자 확인).
모든 길이·해상도·녹화 동시 실행은 미검증입니다.
빠른 처리·원본 완전 보존을 보장하지 않습니다. 실패한 latent 경로는 제거했습니다.
