# 메인 PC 설치 녹화

4070 Ti SUPER 16GB / RAM 32GB에서 업스케일 성공 사례는 있지만 녹화 동시 실행은 미검증입니다. 녹화와 렌더를 분리해서 준비합니다.

1. 폴더 선택·설치기·모델 배치 과정을 녹화합니다.
2. 모델 다운로드는 링크·위치만 보여주고 대기는 편집합니다. 미리 받아둔 모델이면 그 사실을 표시합니다.
3. 재시작 → 모델·입력 선택 → 짧은 샘플 실행 버튼까지 녹화합니다.
4. 녹화를 종료한 뒤 업스케일을 기다립니다.
5. 결과 재생·원본 비교를 별도로 녹화합니다. '처리 대기 구간 생략'으로 연결합니다.

렌더와 녹화를 억지로 동시에 유지할 필요가 없습니다. 실행 순간은 휴대폰으로 찍어도 됩니다.
이미 설치된 환경을 신규 설치 성공처럼 설명하지 마세요. 정상 환경을 지우며 재현할 필요는 없습니다.
시간 비교에는 녹화 동시 여부, 해상도·배율·길이와 첫 실행/재실행을 구분하세요.
