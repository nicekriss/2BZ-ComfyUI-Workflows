# FastH3 + USDU v1.1.1

현재 캔버스의 26노드·29링크 구성으로 배포본을 갱신했습니다.

- 특정 인종·성별 기본 지시 제거. 범용 복원 프롬프트와 선택 추가 묘사 사용.
- 실제 2배 출력·2스텝을 기준으로 설명 정정. 구 RTX SR 및 단정적인 얼굴 보존 설명 제거.
- SolAttn v5 원본 해시 검증, 기존 다른 파일 보존, 패키지 자동 업데이트 제거.
- VSA chunked API/BF16/GPU 검사 및 작은 CUDA 실행 테스트 추가.

노드가 보인다는 이유만으로 가속이 동작한다고 판단하면 안 됩니다. 로컬 comfy-kitchen 0.2.31은 chunked API가 없어 검사에 실패했습니다. 격리된 공식 0.2.32 Windows wheel은 RTX 3090에서 작은 CUDA 실행까지 통과했습니다. 전체 H3 재실행 및 새 범용 프롬프트의 영상 품질 비교는 미실시입니다.
