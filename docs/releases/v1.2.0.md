# FastH3 + USDU 설치 패키지 v1.2.0

## 다운로드 → 실행 → 확인

1. 아래 **Assets → 2BZ-FastH3-USDU-installer-v1.2.0.zip**을 받습니다. **Source code (zip)이 아닙니다.**
2. 로컬 쓰기 가능한 폴더에 전부 압축 해제합니다. 예: `C:\AI-Setup\FastH3-USDU`. ZIP 전체를 custom_nodes에 넣지 말고, BAT만 따로 옮기지 마세요.
3. **START-HERE-ko.md** 확인 → ComfyUI 저장·종료 → **Install-SolAttn-MiniMax.bat → Install-USDU-H3.bat** 순서로 실행합니다. 실제 main.py가 있는 ComfyUI 폴더를 선택하세요.
4. README의 모델 4개를 준비하고 ComfyUI를 재실행합니다. 모델 약41GB와 Git for Windows는 별도입니다.
5. **Check-ComfyUI.bat**에 실제 로컬 서버 주소 입력 → `SERVER READY` + 모델4개 `MODEL LISTED` 확인 → **2BZ_FastH3_USDU.json**을 열고 입력 영상 선택 → 짧은 영상 실행 → 새 MP4를 재생합니다.

어텐션 `DEPENDENCIES READY`만으로 전체 설치 성공은 아닙니다. 네 단계 성공 기준, 복구와 호환성 제한은 START-HERE-ko.md에 있습니다.

## 해석과 지원 범위

이번3090 24GB/RAM64GB·같은15초·2752×1536·2스텝/.20에서 FastH3 구성이 약2배 빨랐습니다. 각1회 성공 실행이며 **VSA만의 가속 수치가 아닙니다**. FastH3 USDU의 성공 시간은 메모리 추정 계수1.0 보완 후 실행으로 실패 시간은 제외했습니다. 길이가 유일한 OOM 원인이라고 확정하지 않았습니다.

실측은 로컬RealESRGAN_x2.pth, 배포는 공식x2plus입니다. 파일 동일성 및 모든 환경에서 같은 시간·화질은 보장하지 않습니다. 자세한 조건은 BENCHMARK.md.

Windows/NVIDIA SM80+용. 기존4070 Ti SUPER16GB/RAM32GB 성공은 사용자 확인이며 이번3090 실측과 별개입니다. **새 ZIP으로 깨끗한 PC에서 설치부터 전체 렌더까지, 녹화 동시 실행은 미검증**입니다.
H3 코어 패치는 검증된2파일 해시가 맞을 때만 적용합니다. 미확인 버전이나 수정본을 덮어쓰지 않으며, 무작정 최신/nightly·다운그레이드로 해결하라고 안내하지 않습니다. 설치기 실행 로직은 rc2와 같습니다.
