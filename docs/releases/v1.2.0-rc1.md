# 메인컴 테스트용 SolAttn 설치기 v1.2.0-rc1

ZIP 압축 해제 → ComfyUI 종료 → Install-SolAttn-MiniMax.bat 실행 → ComfyUI 폴더 선택 → 표시된 Python 확인.

VSA 검사가 실패하면 comfy-kitchen을 정확히 0.2.32로 설치하고 다시 CUDA 테스트합니다. Torch와 다른 의존성은 변경하지 않습니다. 기존 파일 백업, 자동 복구, 수동 Restore 실행 파일을 포함합니다.

검증: 격리 환경에서 0.2.31 → 0.2.32 실제 wheel 설치, RTX 3090 VSA CUDA 실행, SolAttn 원본 다운로드/해시, 수동 복구, 강제 오류 후 자동 복구를 확인했습니다. 복구 후 원본 58개 파일 해시가 일치했습니다. PowerShell 문법 검사를 통과했습니다. GUI 클릭 경로 및 메인컴 전체 H3 실행은 미검증입니다.

이것은 사전 테스트용 Release입니다. 기존 정식 v1.1.1을 대체하지 않습니다. 동봉 워크플로우는 v1.1.1이며 설치기 사용법은 START-HERE-ko.md를 따르세요.

USDU H3 포크와 모델 파일은 별도 설치가 필요합니다. 실패 시 ComfyUI/user/2bz-solattn-installer 안의 로그를 확인하세요.
