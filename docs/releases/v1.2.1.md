# FastH3 + USDU v1.2.1 · 한국어 / English

**Assets의 `2BZ-FastH3-USDU-installer-v1.2.1.zip`을 받으세요. Source code ZIP이 아닙니다.**

1. 쓰기 가능한 로컬 폴더에 전체 압축을 풉니다. BAT만 옮기거나 ZIP 전체를 custom_nodes에 넣지 마세요.
2. `START-HERE-ko.md`를 읽고 ComfyUI 저장·종료 후 `Install-SolAttn-MiniMax.bat` → `Install-USDU-H3.bat`을 실행합니다.
3. ComfyUI를 다시 열고 `2BZ_FastH3_USDU.json`을 로드합니다.
4. **① 모델 다운로드** 노트에서 모델 4개의 링크를 클릭하고 안내된 폴더에 저장합니다. 모델 약 41GB와 Git for Windows는 별도입니다.
5. 모델 목록 새로고침 → 로더 선택 → `Check-ComfyUI.bat`의 `SERVER READY` / 네 개의 `MODEL LISTED` 확인 → 짧은 입력 영상으로 실행해 새 MP4를 확인합니다.

영어 사용자는 **`START-HERE-en.md` + `2BZ_FastH3_USDU_EN.json`**을 사용하세요. 두 워크플로우는 설명 언어만 다르며 연결·프롬프트·실행 설정은 같습니다.

- 워크플로우 안에 모델 직접 다운로드 링크와 저장 위치 추가.
- 노드·그룹 제목과 설명 노트를 번역한 영문판 동봉.
- **⑥ 최신 테스트 결과** 그룹에 비교표 배치: 일반 H3 + Turbo USDU 96분 37초 / FastH3 USDU 48분 40초 / FastH3 단일 노드 47분 36초.

## English quick start

Download the installer ZIP under Assets, extract the entire package into a writable local folder, and read **START-HERE-en.md**. Close ComfyUI before running the two installers. Reopen ComfyUI, load **2BZ_FastH3_USDU_EN.json**, then use its model-download MarkdownNote to download the four models into the indicated folders. Refresh model lists, select the files, run the checker and render a short video to verify the output.

This patch adds direct model links, a fully translated workflow and a visible benchmark group. Execution settings and installer behavior are unchanged. The final selected method is FastH3 + USDU, not the slightly faster single-node experiment that showed more distortion in user review.

Both workflow structures/layouts and matching execution settings were checked; all four model URLs responded successfully. **Clean-PC installation through a full render, and rendering while recording, remain unverified.** Windows/NVIDIA SM80+ compatibility restrictions still apply. See the included guides for checks, recovery and a privacy-conscious error-report template. No automatic log uploads.
