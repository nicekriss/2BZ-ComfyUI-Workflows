# LTX 2.5 IC-LoRA — 내 영상에 효과만 입히기 (물 · 밤 · 사람 지우기)

찍어둔 영상 하나를 넣고 한 줄만 적으면, 사람·카메라·배경은 그대로 두고 **효과만** 바꿉니다.

| 효과 | 한 줄 요청 예시 |
|---|---|
| **A 물 채우기** | `서 있는 사람 무릎까지 흙탕물이 차 있다` |
| **B 낮 → 밤** | `보름달이 뜬 밤, 가로등 불빛` |
| **C 사람·물체 지우기** | `사람을 지운다` |

**[워크플로 다운로드 (JSON)](https://raw.githubusercontent.com/nicekriss/2BZ-ComfyUI-Workflows/main/LTX2.5-ICLoRA/2BZ_LTX25_ICLoRA_3FX_Water_Night_CleanPlate.json)** — 링크에서 우클릭 → 다른 이름으로 저장 후 ComfyUI 화면에 끌어다 놓으세요.

## 필요한 것

**ComfyUI 0.37.0 이상** + 커스텀 노드 3개 (Manager → Install Missing Custom Nodes, 또는 아래 이름으로 검색)

- `ComfyUI-LTXVideo`
- `ComfyUI-VideoHelperSuite`
- `rgthree-comfy`

모델 다운로드 링크(클릭 = 바로 다운로드)와 넣을 폴더는 워크플로 안 **「모델 받는 방법」** 메모에 있습니다. LTX 2.5 본체와 IC-LoRA 3개는 Hugging Face 로그인 후 각 페이지에서 **Agree and Access** 를 한 번 눌러야 받아집니다.

## 쓰는 법

1. ① 에 영상 업로드 — 24fps·121프레임(약 5초)으로 자동 변환, **세로 영상은 세로, 가로 영상은 가로로** 자동으로 맞춥니다 (긴 변 1920)
2. ② 스위치에서 효과 하나 켜기 (하나를 켜면 나머지는 자동으로 꺼집니다)
3. ③ 에 원하는 걸 한국어로 짧게 — 영어 프롬프트는 소형 Gemma4 가 영상 첫 장면을 보고 써줍니다
4. 실행

## 확인한 환경 (각 조건 1회 실행)

| GPU | 설정 | 시간 | 비고 |
|---|---|---|---|
| RTX 3090 24GB | 1920×1088 · 121프레임 | 약 11 ~ 13분 | |
| RTX 4070 Ti SUPER 16GB | 1920×1088 · 121프레임 | 436초 | VRAM 최대 13.9GB, **시스템 RAM 32GB 중 30.2GB 사용** |

- RAM 32GB 이하라면 **4K 원본은 FHD로 줄여서** 넣으세요. 로더가 원본 해상도로 읽습니다.
- 메모리가 부족하면 ① 의 `frame_load_cap` 을 97로, 그래도 안 되면 「해상도 — 긴 변」을 1280으로.

## 알아둘 것

- **폰 HDR 영상은 결과 색이 바랩니다.** 코어 노드 `Convert Image Color Space`(source **HDR** → destination **sRGB**)를 「타일 디코드」와 「영상 합치기」 사이에 끼우세요. 일반 영상에는 쓰지 마세요. 찍을 때 폰의 HDR 동영상 옵션을 끄면 이 문제가 없습니다.
- **2단계 업스케일을 붙이지 마세요.** IC-LoRA 는 한 번에 원본 해상도로 돌리는 게 공식 권장이고, latent 업스케일을 붙이면 효과가 지워지거나 얼굴이 바뀝니다.
- **지우기**는 대상이 화면 한가운데를 크게 차지하면 잘 안 됩니다.
- **밤**은 4초(97프레임)로 학습돼서 길게 돌리면 뒤로 갈수록 흐트러질 수 있습니다.
- 한 번에 최대 185프레임(약 7.7초)까지. 마스크 없이 화면 전체에 적용됩니다.
