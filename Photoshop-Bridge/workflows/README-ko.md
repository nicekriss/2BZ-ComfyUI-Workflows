# ComfyUI에서 실행 내용 확인하기

플러그인 결과 창의 **이 결과의 워크플로우 저장**을 누르면 그 결과를 만든 실제 실행 그래프를 JSON으로 저장합니다. 실패한 작업은 연결 설정의 **마지막 실행 워크플로우 저장**으로 확인합니다. 새 버전 이전의 결과는 ComfyUI 실행 이력이 남아 있어야 내보낼 수 있습니다.

1. 작업 중인 ComfyUI 워크플로우를 저장하고 새 탭을 만드세요.
2. 저장한 JSON을 캔버스에 끌어 놓거나 워크플로우 열기로 여세요. ComfyUI가 노드와 연결을 자동 배치합니다.
3. 모델·LoRA·프롬프트·변형 강도·마스크 확장/블러 값을 확인하세요. 같은 시드로 비교하려면 KSampler의 생성 후 시드 변경을 `fixed`로 두세요.

싱크한 이미지·선택 마스크의 파일 이름도 보존합니다. 실제 이미지 파일은 **원래 연결한 ComfyUI의 input/TooBusyPS 폴더**에 있어야 합니다. JSON 하나에 이미지나 모델이 포함되는 것은 아닙니다. 다른 PC로 옮길 때는 해당 입력 파일과 모델도 함께 준비하세요. 포토샵에 적용하는 단계는 이 그래프 밖에서 수행됩니다.

`TooBusy-Photoshop-Pro.api.json`은 전체 기능의 기본 구조입니다. 실제 결과를 재현할 때는 위 버튼으로 내보낸 실행 그래프를 사용하세요. 기본 구조로 새 작업을 시작한다면 이미지 로더 3곳에서 입력·뎁스/포즈 참조·스타일 참조 이미지를 고르고, 모델 파일을 선택하세요. 선택 마스크는 기본 입력 이미지 로더의 마스크 편집기로 만듭니다. 필요한 제어 스위치만 켜세요.

이 파일은 ComfyUI의 API JSON 가져오기를 사용합니다. 가져오기가 없는 구형 ComfyUI 프런트엔드에서는 프런트엔드 호환성을 확인해야 합니다. 기본 파일이나 내보내기로 현재 ComfyUI의 열린 탭을 자동 교체하지 않습니다.
