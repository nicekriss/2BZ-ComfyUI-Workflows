# TooBusy AI 설치 안내

**TooBusyAI-Setup.exe 하나를 실행하면 됩니다.** Windows용이며 이미 설치된 ComfyUI를 사용합니다. 새 ComfyUI 설치나 기존 ComfyUI 업데이트는 하지 않습니다. 설치기 실행을 위해 별도로 Python이나 Git을 설치할 필요는 없습니다. Photoshop과 Creative Cloud Desktop은 설치되어 있어야 합니다.

1. **ComfyUI 폴더**를 고릅니다. `main.py`가 있는 폴더나 Windows Portable의 상위 폴더를 선택할 수 있습니다.
2. ComfyUI를 실행한 상태에서 **① 설치 전 점검**을 누르면 사용 중인 공유 모델 경로도 확인합니다. 외부 모델 폴더를 찾지 못하면 공유 모델 폴더를 지정합니다.
3. 진행하던 ComfyUI 작업을 저장하고 ComfyUI를 종료한 뒤 **② 필요한 항목 설치**를 누릅니다. 노드와 모델, Bridge 및 연결 파일을 준비합니다.
4. 평소 방법으로 ComfyUI를 다시 실행합니다. 주소의 포트가 실제 ComfyUI 주소와 맞는지 확인하고 **③ 연결 검사**를 누릅니다.
5. **④ 포토샵 플러그인 설치**를 누르고 Creative Cloud의 설치 안내를 완료합니다. CCX 파일은 실행 파일에 포함되어 있습니다.
6. **연결 파일·설치 결과 폴더** 버튼을 누릅니다. Photoshop의 TooBusy AI 패널에서 상단 연결 상태 → **설치 연결 파일 열기**를 눌러 해당 폴더의 `TooBusy-connection.json`을 한 번 선택합니다.
7. 캔버스를 싱크하고 생성합니다. 이후에는 ComfyUI를 켜두고 Photoshop에서 작업하면 됩니다.

## 설치되는 구성

- TooBusy Bridge: 이미지 송수신 커스텀노드, PC별 연결 키.
- KJNodes, IPAdapter Plus: 없는 패키지만 고정 버전으로 설치합니다. 이미 있으면 유지합니다.
- 전체 기능 작업팩의 모델 8종: Zeniji Mix K-Webtoon, painterly LoRA, 라인아트 ControlNet, Union ControlNet, DA3, SDPose, IPAdapter, CLIP Vision.
- 모든 모델이 없으면 약 **17.8 GiB** 다운로드합니다. 기존 동일 파일은 해시 확인 후 재사용합니다. 같은 드라이브에서는 하드링크를 우선 사용합니다. 다른 드라이브의 파일은 필요한 경우 복사하므로 추가 공간이 필요합니다.
- 라인아트 모델은 원저자의 BF16 파일을 받은 뒤 검증한 방식으로 FP16 변환합니다.

## 중단·재설치

다운로드 중 중지를 누르면 다음 실행에서 이어받습니다. 기존 모델을 덮어쓰거나 기존 노드를 자동 업데이트하지 않습니다. Python 의존성 설치는 실행 중인 한 명령이 끝난 뒤 중지할 수 있습니다. 재설치 시 기존 Bridge 연결 키를 유지합니다.

### Civitai 로그인 모델도 설치 창에서 계속 받기

설치 창의 **API 키 발급 페이지**를 눌러 Civitai 계정 설정을 엽니다. 로그인 후 **API Keys**에서 만든 키를 설치 창의 **Civitai API 키** 입력란에 붙여넣으세요. 비밀번호가 아닌 API 키입니다.

미리 입력하지 않아도 됩니다. 다운로드 중 인증이 필요하면 입력 창이 열립니다. 그 창의 발급 페이지 버튼으로 키를 만든 뒤 붙여넣고 확인하면 **멈춘 모델부터 자동으로 이어받고, 나머지 Civitai 모델에도 같은 키를 사용합니다.** 키가 거부되면 다시 입력할 수 있습니다. 모델을 직접 옮기거나 설치를 처음부터 시작할 필요가 없습니다.

키는 가려서 표시하고 이번 실행의 메모리에만 보관합니다. 로그·설정·연결 파일에는 저장하지 않으며 다운로드용 Civitai HTTPS API에만 전송합니다. 창을 닫고 다시 실행하면 키를 다시 입력해야 합니다. 인증을 취소해도 받은 부분은 보존합니다. 유효한 키가 있어도 해당 계정에 모델 이용권한이 없는 경우에는 권한 확인이 필요합니다.

다운로드 출처와 SHA-256은 배포 ZIP의 `dependencies.json`, 설치 소스의 `installer/dependencies.json`에 기록되어 있습니다. 인증 방식은 [Civitai 공식 API 안내](https://github.com/civitai/civitai/wiki/REST-API-Reference#authorization-header)를 따릅니다.

현재 ComfyUI에 DA3·SDPose 등 필요한 노드가 없거나 기존 커스텀노드 버전이 맞지 않으면 연결 검사가 구체적인 누락 항목을 표시합니다. 그 경우 해당 ComfyUI의 업데이트 기능으로 환경을 맞춰야 합니다. 설치기가 사용자의 환경을 강제로 교체하지는 않습니다.

연결 파일과 로그는 `%LOCALAPPDATA%/TooBusyAI/Setup/설치별폴더/`에 저장됩니다. 연결 파일은 해당 PC용이므로 개발 PC의 파일을 의뢰인에게 복사하지 않습니다.

검증: 이 PC에서 EXE 실행·기존 환경 점검·연결 검사, Adobe CCX 실제 설치를 확인했습니다. 의뢰인 PC에서 모든 모델을 새로 받아 생성까지 완료하는 최종 검수는 현장에서 진행해야 합니다.

## 0.2.2 · 기존 사용자는 CCX만 업데이트

기존 0.2.0/0.2.1 사용자는 배포 페이지의 **toobusy.photoshop.bridge_PS.ccx**만 받아 열고 Adobe 설치 화면에서 업데이트하세요. 전체 설치기나 모델을 다시 받을 필요가 없습니다. 설치 후 Photoshop의 플러그인 패널을 다시 여세요. 이전 코드가 계속 보이면 작업을 저장하고 Photoshop을 다시 시작하세요.

이 버전부터 패널 우측 위 **연결됨/연결 설정 → 업데이트 확인 → 새 버전 업데이트 받기**로 플러그인 업데이트를 시작합니다. 새 CCX를 내려받아 SHA-256을 확인한 뒤 Adobe 설치 화면을 엽니다. Adobe의 열기/설치 확인은 직접 완료해야 합니다. 다운로드 완료를 설치 완료로 표시하지 않습니다. 같은 배포 ID를 유지하므로 연결 정보·모델 배합·설정 저장 위치가 바뀌지 않습니다.

업데이트 확인은 누를 때만 실행합니다. 같은 저장소의 SD-PPP·YuE2 등 다른 제품은 제외합니다. 모델·커스텀노드는 이 버튼으로 변경하지 않습니다. 향후 서버 구성이 바뀌는 릴리스는 호환 CCX를 단독 제공하지 않고 배포 페이지에서 별도 설치 안내를 제공합니다. 이번 0.2.2의 서버 구성은 이전과 동일합니다.

결과 창에는 **이 결과의 워크플로우 저장**, 연결 설정에는 실패한 실행도 확인할 수 있는 **마지막 실행 워크플로우 저장**이 있습니다. 같은 ComfyUI의 새 탭에서 JSON을 열면 실제 모델·LoRA·프롬프트·시드·마스크 경로를 노드로 확인할 수 있습니다. 입력 이미지 파일은 같은 ComfyUI에 남아 있어야 합니다. ZIP의 `workflows/`에는 전체 기능의 기본 구조와 사용 안내도 포함됩니다.

## 0.2.3 · 선택 영역 인페인팅 개선

0.2.2 사용자는 연결 설정 → 업데이트 확인 → 업데이트 받기로 새 CCX를 열고 Adobe 설치를 완료하세요. 처음 설치하는 의뢰인에게는 0.2.3 전체 설치 ZIP을 전달하세요. 이번 수정은 모델/커스텀 노드 재설치가 필요하지 않습니다. 업데이트 후 플러그인 패널을 다시 열고 **선택 영역을 다시 싱크**하세요.

작은 눈·얼굴 영역을 주변 맥락과 함께 잘라 긴 변 1024px에서 처리하고 원래 위치로 되돌립니다. Differential Diffusion과 원본 색감 보정을 적용해 기존 테스트의 눈 감기 실패와 회색 패치를 줄였습니다. 모델·LoRA·프롬프트·변형 강도 선택은 유지합니다. 라인아트를 켜면 기존 눈 모양을 유지하려는 제어가 걸릴 수 있습니다.

WAI와 Zeniji 얼굴의 비교 생성 및 46개 자동 검사를 통과했습니다. 모든 그림/모델의 품질을 보장하거나 보고된 피부 비늘 증상의 완전 해결을 뜻하지 않습니다. 신규 의뢰인 PC에서 연결·생성·적용·업데이트 확인은 설치 후 확인하세요. [비교 결과와 검증 한계](https://github.com/nicekriss/2BZ-ComfyUI-Workflows/blob/main/Photoshop-Bridge/qa/illustrious-inpaint/REPORT.md)를 참고하세요.

## 0.2.4 · 인페인팅 기본 설정과 입력 편의

기존 0.2.2/0.2.3 사용자는 연결 설정 → 업데이트 확인으로 CCX를 업데이트하세요. Adobe 설치를 완료한 뒤 플러그인 패널을 다시 여세요. 모델/커스텀 노드 재설치가 필요하지 않습니다.

- 선택 영역 수정을 켜면 라인아트 구조 유지를 끕니다. 필요하면 직접 다시 켤 수 있으며, 이 명시적인 선택은 재실행에도 유지됩니다. 이전 버전에서 인페인팅이 켜진 채 저장된 설정은 최초 복원 시 라인아트를 끕니다.
- 파지티브의 '어떤 그림으로 완성할까요?' 안내 문구를 제거했습니다. 전체 삭제하면 빈칸이며 빈 프롬프트로 생성할 수 있습니다. 프롬프트 편집은 입력 중에도 저장합니다.
- 생성 옵션 옆 '설정 초기화'는 프롬프트·기능 체크·강도·단계·CFG·시드·모델·LoRA를 기본값으로 돌립니다. 연결 정보, 저장한 모델 조합, 싱크 이미지와 결과 목록은 유지합니다.

이번 릴리스는 기본 설정과 UI 동작 수정이며, 피부 비늘 현상의 원인을 확정했다는 의미는 아닙니다.
